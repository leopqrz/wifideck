02

Architecture

One root systemd service on localhost owns every privileged operation. The browser holds no privilege — it renders streams and issues token-authed commands.

  Mac browser  ──HTTP + WebSocket──▶  FastAPI backend  (Kali VM · 127.0.0.1:8787)
  React SPA                            │
                                        ├─ StatusService   → lsusb / iw / nmcli / ip
                                        ├─ ModeService     → iw set type · NM handoff
                                        ├─ ScanService     → nmcli (managed) · airodump (monitor)
                                        ├─ CaptureService  → airodump-ng -w → csv / pcap
                                        ├─ ShareService    → sysctl · iptables (NAT)
                                        ├─ HealthWatcher   → USB presence · -71 detection
                                        └─ AuditService    → gated active modules (P7)
                                        │
                        runs as root systemd service, localhost-bound, token-authed

04

Why build it · the gap

Reuse, don't reinvent

  • Kismet — great web sniffer + API; an optional capture engine, not a controller.
  • aircrack-ng — the capture/attack primitives we shell out to.
  • airgeddon · wifite2 — terminal workflows; reference for phase 07.
  • WiFi Pineapple UI — the dashboard UX to aspire to.

What's actually missing

  • A unified, friendly, live adapter-control dashboard — mode, scan, capture, and sharing in one place.
  • Tailored to the VM-on-Mac workflow, including the USB-passthrough failure modes.
  • For people who don't want to memorize iw / airmon / iptables.
  • That polished web tool doesn't exist yet. This is the gap.
